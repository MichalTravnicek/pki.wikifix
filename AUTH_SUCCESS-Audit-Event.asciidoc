= Overview =

The `AUTH_SUCCESS` audit event is generated when authentication succeeded.

Properties:

* `Outcome`: `Success`
* `AuthMgr`: the authentication manager instance name that did this authentication

*Note:* In PKI 10.5 this event is renamed to `AUTH`.

= Examples =

Use PKI CLI to authenticate as admin user:

----
$ pki -n caadmin ca-user-find
----

The server will generate the following logs:

----
[AuditEvent=AUTH_SUCCESS][SubjectID=caadmin][Outcome=Success][AuthMgr=certUserDB
AuthMgr] authentication success
----
