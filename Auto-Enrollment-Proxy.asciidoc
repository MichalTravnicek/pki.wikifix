The server supports an link:http://directory.fedoraproject.org/wiki/Windows_Certificate_Auto_Enrollment[Auto-Enrollment Proxy] (AEP) for Windows, which allows users and computers in a Microsoft Windows® domain to automatically enroll for certificates issued from Certificate System.

This feature is no longer supported in PKI 10. If you wish to contribute, please take a look at link:https://www.dogtagpki.org/wiki/PKI_Developers[this page].
