= Overview =

This page describes the procedure to build PKI ACME responder as a container.

= Prerequisites =

To install Podman:

----
$ dnf install podman
----

To install Docker:

----
$ dnf install docker
----

= Dockerfile =

The `Dockerfile` is located at https://github.com/dogtagpki/pki/blob/master/Dockerfile.

= Building Container Image =

To build with Podman:

----
$ podman build \
    --build-arg COPR_REPO=@pki/master \
    --target pki-acme \
    --tag pki-acme \
    .
----

To build with Docker:

----
$ docker build \
    --build-arg COPR_REPO=@pki/master \
    --target pki-acme \
    --tag pki-acme \
    .
----

= Pushing Container Image to Quay.io =

----
$ podman tag pki-acme:latest quay.io/<username>/pki-acme:latest
$ podman push quay.io/<username>/pki-acme:latest
----

= Configuring Autobuild on Quay.io (WIP) =

* Open https://quay.io/repository
* Click a container repository (e.g. *dogtagpki/pki-acme*)
* Click *Builds*
* Click *Create Build Trigger*
* Click *GitHub Repository Push*
* Select a source repository (e.g. *dogtagpki/pki*)
* Select *Trigger only on branches and tags matching a regular expression*
* Enter regular expression: `heads/master`
* Unselect *Add latest tag if on default branch*
* Click *Continue*
* Enter Dockerfile location: `/Dockerfile`
* Enter Docker context: `/`
* Click *Continue*

= Configuring Autobuild on Docker Hub =

* Open https://hub.docker.com
* Select a container repository (e.g. *dogtagpki/pki-acme*)
* Click *Builds*
* Click *Configure Automated Builds*
* Click *+* next to *BUILD RULES*
* Enter:
** Source Type: *Branch*
** Source: `master`
** Docker Tag: `latest`
** Dockerfile location: `Dockerfile`
** Build Context: `/`
** Autobuild: *Enabled*
** Build Caching: *Enabled*
* Click *+* next to *BUILD ENVIRONMENT VARIABLES*
* Enter:
** Key: `COPR_REPO`
** Value: `@pki/master`
* Click *Save and Build*
