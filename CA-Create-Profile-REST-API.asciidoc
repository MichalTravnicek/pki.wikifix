= Request =

== JSON Request ==

* **Path:** `/ca/rest/profiles`
* **Method:** `POST`
* **Authentication:** required
* **Content:** `ProfileData` in JSON format

== Raw Request ==

* **Path:** `/ca/rest/profiles/raw`
* **Method:** `POST`
* **Authentication:** required
* **Content:** `ProfileData` in raw format

= Response =

== JSON Response ==

* **Code:** 201
* **Content:** `ProfileData` in JSON format
