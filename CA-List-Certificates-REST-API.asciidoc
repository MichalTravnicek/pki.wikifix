= API v1 =

== Request ==

* **Path:** `/ca/rest/certs`
* **Method:** `GET`
* **Query Parameters:**
** `status`: string
** `maxResults`: integer
** `maxTime`: integer
** `start`: integer
** `size`: integer
* **Content:** None

== Response ==

=== Success ===

* **Code:** `200`
