= Request =

* **Path:** `/ca/rest/profiles`
* **Method:** `GET`
* **Authentication:** required
* **Query Parameters:**
** `start`: Page start
** `size`: Page size
** `visible`: Return visible profiles: none, `true`, `false`
** `enable`: Return enabled profiles: none, `true`, `false`
** `enableBy`: Return profiles enabled by specified user
