= Overview =

This service can be used for certificate enrollment and renewal.

= Enrollment =

== Request ==

* **Operation:** `POST /ca/ee/ca/profileSubmit`
* **Parameters:**
** `renewal`: `false`
** `profileId`: Profile ID
** `authorityId`: Authority ID
** `cert_request_type`: Request type: `pkcs10`, `crmf`, `cmc`, `keygen`
** `cert_request`: CSR
** `requestor_name`: Requestor
** `xmlOutput`: XML output: `true`, `false`

== Response ==

= Renewal =

== Request ==

* **Operation:** `POST /ca/ee/ca/profileSubmit`
* **Parameters:**
** `renewal`: `true`
** `profileId`: profile ID
** `serial_num`: serial number
** `xmlOutput`: XML output (`true` or `false`)
