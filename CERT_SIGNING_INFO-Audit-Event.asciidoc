The `CERT_SIGNING_INFO` audit event is generated when CA is started to indicate which key is used to sign certificates.

For the host CA, the log will not include an authority ID:

----
[AuditEvent=CERT_SIGNING_INFO][SubjectID=$System$][Outcome=Success][SKI=5C:A8:93
:F7:73:08:0D:41:A6:99:89:34:F9:BE:F1:6E:0D:7C:D4:21] certificate signing info
----

For lightweight sub-CA, the log will include the authority ID:

----
[AuditEvent=CERT_SIGNING_INFO][SubjectID=$System$][Outcome=Success][SKI=5C:A8:93
:F7:73:08:0D:41:A6:99:89:34:F9:BE:F1:6E:0D:7C:D4:21][AuthorityID=f6276562-a11c-4
a68-b752-2679b2a40962] certificate signing info
----
