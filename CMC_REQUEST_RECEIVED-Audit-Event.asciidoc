= Overview =

The `CMC_REQUEST_RECEIVED` audit event is generated when a CMC request is received.

= Examples =

Use CMC to issue subordinate CA certificates (see link:CMC_SIGNED_REQUEST_SIG_VERIFY[CMC_SIGNED_REQUEST_SIG_VERIFY]).

The root CA will generate the following events:

----
[AuditEvent=CMC_REQUEST_RECEIVED][SubjectID=caadmin][Outcome=Success][CMCRequest=...] CMC request received
----
