= Overview =

The `CMC_RESPONSE_SENT` audit event is generated when a CMC response is sent.

= Examples =

Use CMC to issue subordinate CA certificates (see link:CMC_SIGNED_REQUEST_SIG_VERIFY[CMC_SIGNED_REQUEST_SIG_VERIFY]).

The root CA will generate the following events:

----
[AuditEvent=CMC_RESPONSE_SENT][SubjectID=caadmin][Outcome=Success][CMCResponse=...] CMC response sent
----
