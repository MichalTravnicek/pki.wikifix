= Overview =

The `CONFIG_AUTH` audit event is generated when configuring the authentication in any PKI subsystem.

= Examples =

Use PKI Console to change the authentication configuration:

* Go to *Configuration* -> *Authentication* -> *Authentication Instance*.
* Click *Add*.
* Select a plugin (e.g. `AgentCertAuth`).
* Click *Next*.
* Enter an instance ID (e.g. `test`).
* Click *OK*.

The server will generate the following events:

----
[AuditEvent=CONFIG_AUTH][SubjectID=caadmin][Outcome=Success][ParamNameValPairs=S
cope;;instance+Operation;;OP_ADD+Resource;;test+implName;;AgentCertAuth] authent
ication configuration parameter(s) change
----
