= Overview =

The `CONFIG_CRL_PROFILE` audit event is generated when the CRL configuration in CA subsystem is updated.

= Examples =

Use CA Console to change CRL configuration:

* Go to *Configuration* -> *Certificate Manager* -> *CRL Issuing Points* -> *Master CRL* -> *Updates*.
* Make some changes.
* Click *Save*.

The server will generate the following logs:

----
[AuditEvent=CONFIG_CRL_PROFILE][SubjectID=caadmin][Outcome=Success][ParamNameVal
Pairs=Scope;;crl+Operation;;OP_MODIFY+Resource;;MasterCRL+enableCRLUpdates;;true

;;true+dailyUpdates;;1:00+enableUpdateInterval;;true+autoUpdateInterval;;241+nex
tUpdateGracePeriod;;242+nextAsThisUpdateExtension;;243] CRL profile configuratio
n parameter(s) change
----
