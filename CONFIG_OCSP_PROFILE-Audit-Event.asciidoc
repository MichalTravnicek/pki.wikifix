= Overview =

The `CONFIG_OCSP_PROFILE` audit event is generated when the OCSP configuration in OCSP subsystem is updated.

= Examples =

Use OCSP Console to change OCSP configuration:

* Go to *Configuration* -> *Online Certificate Status Manager* -> *Revocation Info Stores*.
* Select `defStore`.
* Click *Edit/View*.
* Make some changes.
* Click *OK*.

The server will generate the following events:

----
[AuditEvent=CONFIG_OCSP_PROFILE][SubjectID=ocspadmin][Outcome=Success][ParamName
ValPairs=Scope;;ocspStoresRules+Operation;;OP_MODIFY+Resource;;defStore+includeN
extUpdate;;false+byName;;true+implName;;com.netscape.cms.ocsp.DefStore+notFoundA
sGood;;true] OCSP profile configuration parameter(s) change
----
