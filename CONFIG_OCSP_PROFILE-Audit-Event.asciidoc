The `CONFIG_OCSP_PROFILE` audit event is generated when the OCSP configuration in OCSP is updated.

For example, open OCSP Console, go to Configuration -> Online Certificate Status Manager -> Revocation Info Stores, select `defStore`, then click Edit/View. Make some changes, then click OK. The server will generate the following logs:

----
[AuditEvent=CONFIG_OCSP_PROFILE][SubjectID=ocspadmin][Outcome=Success][ParamName
ValPairs=Scope;;ocspStoresRules+Operation;;OP_MODIFY+Resource;;defStore+includeN
extUpdate;;false+byName;;true+implName;;com.netscape.cms.ocsp.DefStore+notFoundA
sGood;;true] OCSP profile configuration parameter(s) change
----
