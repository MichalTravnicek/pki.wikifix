= Plugin Configuration =

----
$ pki-server ca-config-set jobsScheduler.impl.CertPruningJob.class com.netscape.cms.jobs.CertPruningJob
----

= Job Configuration =

To configure certificate pruning job:

----
$ pki-server ca-config-set jobsScheduler.job.certPruning.enabled false
$ pki-server ca-config-set jobsScheduler.job.certPruning.cron "0 0 1 * *"
$ pki-server ca-config-set jobsScheduler.job.certPruning.pluginName CertPruningJob
$ pki-server ca-config-set jobsScheduler.job.certPruning.retention 30
$ pki-server ca-config-set jobsScheduler.job.certPruning.retentionUnit day
$ pki-server ca-config-set jobsScheduler.job.certPruning.summary.enabled false
----
