= Enabling Scheduler =

By default the scheduler is disabled. To enable the scheduler:

----
$ pki-server ca-config-set jobsScheduler.enabled true
----

= Configuring Scheduler Interval =

To configure scheduler interval:

----
$ pki-server ca-config-set jobsScheduler.interval 1
----
