= General Configuration =

To configure job scheduler:

----
$ pki-server ca-config-set jobsScheduler.enabled true
$ pki-server ca-config-set jobsScheduler.interval 1
----

= Plugins =

----
$ pki-server ca-config-set jobsScheduler.impl.PublishCertsJob.class com.netscape.cms.jobs.PublishCertsJob
$ pki-server ca-config-set jobsScheduler.impl.RenewalNotificationJob.class com.netscape.cms.jobs.RenewalNotificationJob
$ pki-server ca-config-set jobsScheduler.impl.RequestInQueueJob.class com.netscape.cms.jobs.RequestInQueueJob
$ pki-server ca-config-set jobsScheduler.impl.UnpublishExpiredJob.class com.netscape.cms.jobs.UnpublishExpiredJob
----

= Certificate Renewal Notifier =

To configure certificate renewal notifier job:

----
$ pki-server ca-config-set jobsScheduler.job.certRenewalNotifier.enabled true
$ pki-server ca-config-set jobsScheduler.job.certRenewalNotifier.cron "0 3 * * 1-5"
$ pki-server ca-config-set jobsScheduler.job.certRenewalNotifier.emailSubject "Certificate Renewal Notification"
$ pki-server ca-config-set jobsScheduler.job.certRenewalNotifier.emailTemplate /var/lib/pki/pki-tomcat/ca/emails/rnJob1.txt
$ pki-server ca-config-set jobsScheduler.job.certRenewalNotifier.notifyEndOffset 30
$ pki-server ca-config-set jobsScheduler.job.certRenewalNotifier.notifyTriggerOffset 30
$ pki-server ca-config-set jobsScheduler.job.certRenewalNotifier.pluginName RenewalNotificationJob
$ pki-server ca-config-set jobsScheduler.job.certRenewalNotifier.senderEmail admin@example.com
$ pki-server ca-config-set jobsScheduler.job.certRenewalNotifier.summary.enabled true
$ pki-server ca-config-set jobsScheduler.job.certRenewalNotifier.summary.emailSubject "Certificate Renewal Notification Summary"
$ pki-server ca-config-set jobsScheduler.job.certRenewalNotifier.summary.emailTemplate /var/lib/pki/pki-tomcat/ca/emails/rnJob1Summary.txt
$ pki-server ca-config-set jobsScheduler.job.certRenewalNotifier.summary.itemTemplate /var/lib/pki/pki-tomcat/ca/emails/rnJob1Item.txt
$ pki-server ca-config-set jobsScheduler.job.certRenewalNotifier.summary.recipientEmail admin@example.com
$ pki-server ca-config-set jobsScheduler.job.certRenewalNotifier.summary.senderEmail admin@example.com
----

= Certificate Publishing =

To configure certificate publishing job:

----
$ pki-server ca-config-set jobsScheduler.job.publishCerts.enabled true
$ pki-server ca-config-set jobsScheduler.job.publishCerts.cron "0 0 * * 2"
$ pki-server ca-config-set jobsScheduler.job.publishCerts.pluginName PublishCertsJob
$ pki-server ca-config-set jobsScheduler.job.publishCerts.summary.enabled true
$ pki-server ca-config-set jobsScheduler.job.publishCerts.summary.emailSubject "Certs Publishing Summary"
$ pki-server ca-config-set jobsScheduler.job.publishCerts.summary.emailTemplate /var/lib/pki/pki-tomcat/ca/emails/publishCerts.html
$ pki-server ca-config-set jobsScheduler.job.publishCerts.summary.itemTemplate /var/lib/pki/pki-tomcat/ca/emails/publishCertsItem.html
$ pki-server ca-config-set jobsScheduler.job.publishCerts.summary.recipientEmail admin@example.com
$ pki-server ca-config-set jobsScheduler.job.publishCerts.summary.senderEmail admin@example.com
----
