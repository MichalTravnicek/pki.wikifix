= Overview =

This page describes the process to configure `SerialNumberUpdateJob` for link:Sequential-Serial-Numbers[Sequential Serial Numbers].

By default, the `SerialNumberUpdateTask` will run every 10 minutes.

WARNING: `SerialNumberUpdateJob` and `SerialNumberUpdateTask` should not be enabled at the same time.

= Configuration =

To change the interval, specify the following parameter in the CA's `CS.cfg`:

----
ca.serialNumberUpdateInterval=<seconds>
----

If the value is `0` or negative, the task will be disabled.
