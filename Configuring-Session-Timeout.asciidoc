= Overview =

The link:https://github.com/dogtagpki/pki/wiki/PKI-Console#session-timeout[Session Timeout] configuration affects how long an idle PKI Console will remain connected to the server. For some, the default 5 minutes timeout might be too short.

The session timeout can be configured during installation (see link:Two-Step-Installation[Two-Step Installation]) or after installation.

= Configuration =

To configure the session timeout, edit the `keepAliveTimeout` parameter in `/var/lib/pki/pki-tomcat/conf/server.xml`:

----
<Server>
    <Service>

        <Connector name="Secure"
            ...
            keepAliveTimeout="300000"
            ...
            />

    </Service>
</Server>
----
