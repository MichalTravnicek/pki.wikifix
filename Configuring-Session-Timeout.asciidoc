= Overview =

The link:https://github.com/dogtagpki/pki/wiki/PKI-Console#session-timeout[Session Timeout] configuration affects how long an idle PKI Console will remain connected to the server. For some, the default 5 minutes timeout might be too short. It's possible to configure it at install time with the link:Two-Step-Installation[Two-Step Installation].

= Configuration Process =

First, run installation step 1.

Edit the `keepAliveTimeout` parameter in `/etc/pki/pki-tomcat/server.xml`:

----
<Server>
    <Service>

        <Connector name="Secure"
            ...
            keepAliveTimeout="300000"
            ...
            />

    </Service>
</Server>
----

Finally, run installation step 2.
