= Overview =

The subsystem debug log can be configured during installation (see link:Two-Step-Installation[Two-Step Installation]) or after installation.

= Configuration =

To configure the debug level, edit the `debug.level` in `/var/lib/pki/pki-tomcat/ca/conf/CS.cfg`:

----
debug.level=0
----
