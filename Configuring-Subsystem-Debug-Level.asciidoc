= Overview =

The subsystem debug log can be configured during installation (see link:Two-Step-Installation[Two-Step Installation]) or after installation.

= Configuration =

To configure the debug level, edit the `debug.level` in `/var/lib/pki/pki-tomcat/<subsystem>/conf/CS.cfg`:

----
debug.level=0
----

= Log Levels =

The PKI log levels are mapped into SLF4J and JUL log levels as follows:

|===
| PKI Log Level | SLF4J Log Level | JUL Log Level

| 0-1 (OBNOXIOUS)
| TRACE
| FINEST

| 2-5 (VERBOSE)
| DEBUG
| FINE

| 6-10 (INFORM)
| INFO
| INFO

| >10
| WARN
| WARNING

|
| ERROR
| SEVERE
|===
