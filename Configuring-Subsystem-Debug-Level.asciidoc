= Overview =

Sometimes it's necessary to increase the subsystem debug log during installation to troubleshoot installation issues.
This can be done using the link:https://www.dogtagpki.org/wiki/Two-Step_Installation[Two-Step Installation] process.

= Configuration Process =

Run installation step 1.

Edit the `debug.level` in `/var/lib/pki/pki-tomcat/ca/conf/CS.cfg`:

----
debug.level=0
----

Finally, run installation step 2.
