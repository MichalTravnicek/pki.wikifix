= Overview =

System certificate profiles are used to generate the initial system certificates during installation (see link:Two-Step-Installation[Two-Step Installation]). These profiles are no longer used after installation.

The templates for system certificate profiles are stored in link:https://github.com/dogtagpki/pki/tree/master/base/ca/shared/conf[/usr/share/pki/ca/conf]. 

* CA signing certificate:
** https://github.com/dogtagpki/pki/blob/master/base/ca/shared/conf/caCert.profile[caCert.profile]

* OCSP signing certificate:
** https://github.com/dogtagpki/pki/blob/master/base/ca/shared/conf/caOCSPCert.profile[caOCSPCert.profile]

* Audit signing certificate:
** https://github.com/dogtagpki/pki/blob/master/base/ca/shared/conf/caAuditSigningCert.profile[caAuditSigningCert.profile]

* Subsystem certificate:
** https://github.com/dogtagpki/pki/blob/master/base/ca/shared/conf/rsaSubsystemCert.profile[rsaSubsystemCert.profile]
** https://github.com/dogtagpki/pki/blob/master/base/ca/shared/conf/eccSubsystemCert.profile[eccSubsystemCert.profile]
** https://github.com/dogtagpki/pki/blob/master/base/ca/shared/conf/ECsubsystemCert.profile[ECsubsystemCert.profile]

* Server certificate:
** https://github.com/dogtagpki/pki/blob/master/base/ca/shared/conf/eccServerCert.profile[eccServerCert.profile]
** https://github.com/dogtagpki/pki/blob/master/base/ca/shared/conf/rsaServerCert.profile[rsaServerCert.profile]
** https://github.com/dogtagpki/pki/blob/master/base/ca/shared/conf/ECserverCert.profile[ECserverCert.profile]

* Admin certificate:
** https://github.com/dogtagpki/pki/blob/master/base/ca/shared/conf/rsaAdminCert.profile[rsaAdminCert.profile]
** https://github.com/dogtagpki/pki/blob/master/base/ca/shared/conf/eccAdminCert.profile[eccAdminCert.profile]
** https://github.com/dogtagpki/pki/blob/master/base/ca/shared/conf/ECadminCert.profile[ECadminCert.profile]

During CA installation these templates will be copied into `/var/lib/pki/<instance>/<subsystem>/conf` which can be configured using the link:Two-Step-Installation[Two-Step Installation].

= Configuration =

To configure a system certificate profile, edit the profile configuration file in `/var/lib/pki/<instance>/<subsystem>/conf` (not in `/usr/share/pki/ca/conf`):

----
id=...
name=...
description=...
profileIDMapping=...
profileSetIDMapping=...
list=<list of numbers>
<number>.default.class=...
<number>.default.name=...
<number>.default.params.<name>=...
----
