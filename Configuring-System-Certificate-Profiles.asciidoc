= Overview =

System certificate profiles are used to generate the initial system certificates during installation.

The system certificate profile templates are stored in link:https://github.com/dogtagpki/pki/tree/master/base/ca/shared/conf[/usr/share/pki/ca/conf]. During CA installation the system certificate profiles will be copied into `/var/lib/pki/<instance>/<subsystem>/conf`.

The profiles can be configured with the link:https://www.dogtagpki.org/wiki/Two-Step_Installation[Two-Step Installation] process.

= Configuration Process =

Run installation step 1.

Edit the profile configuration files in `/var/lib/pki/<instance>/<subsystem>/conf`:

----
id=...
name=...
description=...
profileIDMapping=...
profileSetIDMapping=...
list=<list of numbers>
<number>.default.class=...
<number>.default.name=...
<number>.default.params.<name>=...
----

Finally, run installation step 2.
