= Overview =

System certificate profiles are used to generate the initial system certificates during installation.

The system certificate profile templates are stored in link:https://github.com/dogtagpki/pki/tree/master/base/ca/shared/conf[/usr/share/pki/ca/conf]. During CA installation the system certificate profiles will be copied into `/var/lib/pki/<instance>/<subsystem>/conf`.

To customize system certificates profiles, see link:https://www.dogtagpki.org/wiki/Two-Step_Installation[Two-Step Installation].

See also link:https://www.dogtagpki.org/wiki/CA_Certificate_Profiles[CA Certificate Profiles].

= Profile Configuration =

System certificate profile configuration consists of the following parameters:

----
id=...
name=...
description=...
profileIDMapping=...
profileSetIDMapping=...
list=<list of numbers>
<number>.default.class=...
<number>.default.name=...
<number>.default.params.<name>=...
----

See also link:https://www.dogtagpki.org/wiki/Certificate_Profile_Constraints[Certificate Profile Constraints].
