This document describes the process to create a PKI systemd service with Podman using PKI 11.4 or later.

= Configuring SELinux =

----
$ setsebool -P container_manage_cgroup on
----

= Creating Systemd Service =

To create the systemd service, execute the following command:

----
$ ln -sf /usr/lib/systemd/system/pki-podman.service
    /etc/systemd/system/pki-podman.service
----

Then execute:

----
$ systemctl daemon-reload
----

= Starting Systemd Service =

----
$ systemctl start pki-podman.service
----

= Monitoring Systemd Service =

----
$ journalctl -fu pki-podman.service
----

= Monitoring Podman Container =

----
$ podman logs -f pki-server
----
