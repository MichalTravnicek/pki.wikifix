= Issuing Certificate =

To issue a certificate, prepare a certificate extension configuration in a file (e.g. ca_signing.conf):

----
basicConstraints       = critical, CA:TRUE
subjectKeyIdentifier   = hash
keyUsage               = critical, digitalSignature, nonRepudiation, keyCertSign, cRLSign
----

To issue a self-signed certificate:

----
$ pki nss-cert-request \
    --subject "CN=CA Signing Certificate" \
    --ext ca_signing.conf \
    --csr ca_signing.csr
$ pki nss-cert-issue \
    --csr ca_signing.csr \
    --ext ca_signing.conf \
    --cert ca_signing.crt
----

Availability: PKI 10.9
