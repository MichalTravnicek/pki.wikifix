= Overview =

Since version 10.4.x CA will generate a `DELTA_CRL_GENERATION` event when the delta CRL generation is complete.

= Examples =

Enable delta CRL, use the Web UI to update the CRL.
The server will generate the following log when the delta CRL generation is complete:

----
[AuditEvent=DELTA_CRL_GENERATION][SubjectID=$System$][Outcome=Success][CRLnum=<C
RL number>] Delta CRL generation
----

If `noCRLIfNoRevokedCert` is true and there is no revoked certificates, the server will generate the following log:

----
[AuditEvent=DELTA_CRL_GENERATION][SubjectID=$System$][Outcome=Success][Info=No R
evoked Certificates] Delta CRL generation
----

If the delta CRL generation fails, the server will log the failure reason:

----
[AuditEvent=DELTA_CRL_GENERATION][SubjectID=$System$][Outcome=Failure][FailureRe
ason=<reason>] Delta CRL generation
----
