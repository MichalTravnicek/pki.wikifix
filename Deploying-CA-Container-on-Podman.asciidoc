= Overview =

NOTE: This page is still under construction.

This document describes the process to deploy CA as a container on Podman. The container image is available at link:https://quay.io/repository/dogtagpki/pki-ca[quay.io/dogtagpki/pki-ca].

= Deploying DS Container =

See link:https://github.com/dogtagpki/389-ds-base/wiki/Deploying-DS-Container-on-Podman[Deploying DS Container on Podman].

= Deploying CA Container =

Run the container with the following command:

----
$ podman run \
    --name=ca \
    --hostname=ca.example.com \
    --network=example \
    --network-alias=ca.example.com \
    -p 8080:8080 \
    -p 8443:8443 \
    -d \
    quay.io/dogtagpki/pki-ca
----

Wait until the container is started:

----
$ podman logs -f ca
----

= Verification =

Install the CA signing certificate:

----
$ podman exec ca pki \
    client-cert-import \
    --ca-cert ca_signing.crt \
    ca_signing
----

Retrieve the container information:

----
$ podman exec ca pki info
  Server URL: https://ca.example.com:8443
  Server Version: 11.3.0
----

= Removing CA Container =

----
$ podman rm -f ca
----
