Since version 10.4.x CA will generate a `FULL_CRL_PUBLISHING` event when the full CRL publishing is complete.

For example, use the Web UI to update the CRL.
The server will generate the following events when the full CRL publishing is complete:

----
[AuditEvent=FULL_CRL_PUBLISHING][SubjectID=$System$][Outcome=Success][CRLnum=<CR
L number>] Full CRL publishing
----

If the full CRL publishing fails, the server will generate an event with the failure reason:

----
[AuditEvent=FULL_CRL_PUBLISHING][SubjectID=$System$][Outcome=Failure][CRLnum=<CR
L number>][FailureReason=<reason>] Full CRL publishing
----
