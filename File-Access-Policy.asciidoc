= Rules =

The rules for each PKI server are defined in `/etc/fapolicyd/rules.d/61-pki-<instance>.rules`:

----
allow perm=open dir=/usr/lib/jvm/ : dir=/var/lib/pki/<instance>/work/Catalina/localhost/
----
