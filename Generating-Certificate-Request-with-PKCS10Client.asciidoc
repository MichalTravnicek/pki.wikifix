The `PKCS10Client` command can be used to generate a PKCS #10 request. For example:

----
$ PKCS10Client \
    -d ~/.dogtag/nssdb \
    -p Secret.123 \
    -a rsa \
    -l 1024 \
    -o testuser.csr \
    -n "uid=testuser,ou=people,dc=example,dc=com"
