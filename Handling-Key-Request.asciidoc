= Reviewing Key Request =

To review a key request:

----
$ pki <agent authentication> kra-key-request-review <request ID> --action <action>
----

Available actions:

* `approve`
* `reject`
* `cancel`

= Approving Key Request =

To approve a key request:

----
$ pki -n caadmin kra-key-request-review 0x5319ddf580177086cc73d9386075128e --action approve
------
Result
------
  Request ID: 0x5319ddf580177086cc73d9386075128e
  Key ID: 0x008a590f503cbdf4d20de4de480473f19a
  Type: asymkeyGenRequest
  Status: complete
----
