= Connecting to IRC Server =

Use an IRC client to connect to the IRC server at `irc.libera.chat`.

See also link:https://libera.chat/guides/connect[Connecting to Libera.Chat].

= Registering Nickname =

To register a nickname:

----
/msg NickServ register <password> <email>
----

See also link:https://libera.chat/guides/registration[Nickname Registration].

= Nickname Authentication =

To authenticate the nickname:

----
/msg NickServ identify <password>
----

See also link:https://libera.chat/guides/channels[Using Channels].

= Registering Channel =

To register a channel:

----
/msg ChanServ register <channel>
----

See also link:https://libera.chat/guides/creatingchannels[Creating Channels].
