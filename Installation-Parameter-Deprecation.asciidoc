= Overview =

Installation parameter deprecation is defined in link:https://github.com/dogtagpki/pki/blob/master/base/server/python/pki/server/deployment/pkiparser.py[pkiparser.py]

Deprecated param can be defined with the following tuple:

----
(sections, param, new_section, new_param)
----

The `sections` is a list of sections to check for the deprecated param. None
means the following sections will be checked: `DEFAULT`, `Tomcat`, and `<subsystem>`. See link:https://github.com/dogtagpki/pki/blob/master/base/server/etc/default.cfg[default.cfg].

The `param` is the deprecated param name.

The `new_section` is the proper section of the new param. None means unchanged.

The `new_param` is the new param name.
