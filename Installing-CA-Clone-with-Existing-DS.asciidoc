= Overview =

NOTE: This page is still under construction.

This page describes the process to install CA clone with existing DS instance which has been set up as a replica of the DS instance used by the primary CA.
It is not recommended to install CA clone using the DS instance used by the primary CA directly.

= Prerequisites =

* Install a primary DS
* Install a primary CA using the primary DS
* Install a secondary DS
* link:https://github.com/dogtagpki/389-ds-base/wiki/Configuring-DS-Replication[Configure replication] between the primary and secondary DS
