= Overview =

This page describes the process to install a CA subsystem with random certificate serial numbers. By default CA will use sequential serial numbers.

= Random Certificate Serial Numbers v1 =

To install CA with link:Random-Certificate-Serial-Numbers-v1[Random Certificate Serial Numbers v1], follow the normal CA installation procedure, but specify the following parameter:

----
[CA]
pki_random_serial_numbers_enable=True
----
