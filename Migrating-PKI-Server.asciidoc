= Overview =

This document describes the process to migrate PKI server into a new instance.

= Cloning =

This mechanism works by cloning the old server to the new one, promoting the new one as master, then decommissioning the old one.

* link:Migrating-PKI-9-to-PKI-10[Migrating PKI 9 to PKI 10]

= Export and Import =

This mechanism works by exporting the database and configuration from the old server, installing a new server with the new configuration, then importing the database to the new server.

* link:Migrating-CA-using-General-Mechanism[Migrating a CA using general mechanism]
* link:Migrating-CA-using-Existing-CA-Mechanism[Migrating a CA using existing CA mechanism]
* link:Migrating-CA-with-HSM-using-Existing-CA-Mechanism[Migrating a CA with HSM using existing CA mechanism]
* link:Database-Migration[Database Migration]
