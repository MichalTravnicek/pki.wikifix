To display CA OCSP signing certificate extensions:

----
$ pki-server cert-export ca_ocsp_signing --cert-file ca_ocsp_signing.crt
$ openssl x509 -text -noout -in ca_ocsp_signing.crt
...
        X509v3 extensions:
            X509v3 Authority Key Identifier: 
                keyid:F8:1E:0E:C5:94:6C:FC:2E:5A:38:7A:D9:6E:8E:97:73:E2:EA:A3:3C

            Authority Information Access: 
                OCSP - URI:http://pki.example.com:8080/ca/ocsp

            X509v3 Extended Key Usage: 
                OCSP Signing
            OCSP No Check: 
...
----
