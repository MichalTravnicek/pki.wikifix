= Overview =

The `OCSP_REMOVE_CA_REQUEST` audit event is generated when a CA is attempted to be removed from the OCSP Responder.

= Examples =

Open OCSP Web UI, click *List Certificate Authorities*, click *Remove CA*, then click *OK*.

The server will generate the following events:

----
[AuditEvent=OCSP_REMOVE_CA_REQUEST][SubjectID=ocspadmin][Outcome=Success][CASubj
ectDN=CN=CA Signing Certificate,OU=pki-tomcat,O=EXAMPLE] request to remove a CA 
from OCSP Responder
----
