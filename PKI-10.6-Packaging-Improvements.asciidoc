= Layout Changes =

* The `default.cfg` will be moved from `/etc/pki` to `/usr/share/pki/server/etc`.

= Merging PKI Source Packages =

Currently PKI is distributed using the following source packages:

* `pki-core`
* `pki-console`
* `dogtag-pki-theme`
* `dogtag-pki`

They will be simplified into:

* `pki-core`
* `dogtag-pki`
