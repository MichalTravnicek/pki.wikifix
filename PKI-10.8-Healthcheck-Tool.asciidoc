= Overview =

In version 10.8 PKI will provide a tech-preview of PKI Healthcheck tool.

Warning:

* It does not come with extensive set of healthchecks
* It is not flexible (ie) can run only on pki-tomcat instance

= Current Features =

* Auto-integrates with ipa-healthcheck (ie) ipa-healthcheck invokes pki-healthcheck
* Reuses ipa-healthcheck framework
* Checks if certs in nssdb and CS.cfg match
