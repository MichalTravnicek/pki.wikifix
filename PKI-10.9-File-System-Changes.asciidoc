= Installation Logs =

Previously installation logs were stored in `/var/log/pki/pki-<subsystem>-spawn.<timestamp>.log`.
In PKI 10.9 the installation logs are stored in `/var/log/pki/<instance>/<subsystem>/install.log`.

= Upgrade Logs =

Previously upgrade logs were stored in `/var/log/pki/pki-server-upgrade-<version>.log`.
In PKI 10.9 the upgrade logs are stored in `/var/log/pki/<instance>/upgrade.log`.

= Backup Files =

Previously backup files were stored in `/var/log/pki/server/upgrade`.
In PKI 10.9 the backup files are stored in `/var/log/pki/<instance>/backup`.
