= Overview =

PKI CLI provides commands to access the ACME service.

= Displaying ACME Service Status =

To display ACME service status, execute `pki acme-info`.

If the service is enabled, it will show the status as `Available` with the ACME metadata:

----
$ pki acme-info
  Status: Available
  Terms of Service: https://www.example.com/acme/tos.pdf
  Website: https://www.example.com
  CAA Identities: example.com
  External Account Required: false
----

If the service is disabled, it will show the status as `Unavailable` without the ACME metadata:

----
$ pki acme-info
  Status: Unavailable
----

= Enabling ACME Service =

To enable ACME service:

----
$ pki -u admin -w Secret.123 acme-disable
----

The user must be a member of `Administrators` or `Enterprise ACME Administrators` group.

= Disabling ACME Service =

To disable ACME service:

----
$ pki -u admin -w Secret.123 acme-disable
----

The user must be a member of `Administrators` or `Enterprise ACME Administrators` group.
