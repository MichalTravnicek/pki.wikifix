= Overview

The PKI ACME Directory operation will return the ACME directory as defined in https://tools.ietf.org/html/rfc8555[RFC 8555].

= Request

* *URL:* `/acme/directory`
* *Method:* `GET`
* *Authentication:* Not required
* *Authorization:* Not required

= Response

== Success
* *Code:* `200`

== Unavailable
* *Code:* `503`
