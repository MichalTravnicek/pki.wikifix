= Overview

The PKI ACME Disable operation will disable ACME user services.

= Request

* *URL:* `/acme/disable`
* *Method:* `POST`
* *Authentication:* Required
* *Authorization:* Must be a member of `Administrators` or `Enterprise ACME Administrators` group.

= Response

== Success
* *Code:* `200`

== Unauthenticated
* *Code:* `401`

== Unauthorized
* *Code:* `403`
