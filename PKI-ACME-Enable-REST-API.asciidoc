= Overview

The PKI ACME Enable operation will enable ACME user services.

= Request

* *URL:* `/acme/enable`
* *Method:* `POST`
* *Authentication:* Required
* *Authorization:* Must be a member of `Administrators`

= Response

== Success
* *Code:* `200`

== Unauthenticated
* *Code:* `401`

== Unauthorized
* *Code:* `403`
