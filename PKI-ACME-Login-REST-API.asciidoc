= Overview

The PKI ACME Login operation will authenticate the user, establish a session on the server, return the user profile, and return a cookie containing the session ID.

= Request

* *URL:* `/acme/login`
* *Method:* `POST`
* *Authentication:* Required
* *Authorization:* Not required

= Response

== Success
* *Code:* `200`
* *Content:*

----
{
    "id": "admin",
    "roles": [
        "Administrators"
    ]
}
----

== Unauthenticated
* *Code:* `401`

= Example =

----
$ curl -s --request POST -u admin:Secret.123 https://pki.demo.dogtagpki.org/acme/login | python -m json.tool
{
    "Attributes": {
        "Attribute": []
    },
    "id": "admin",
    "FullName": "Administrator",
    "Roles": {
        "Role": [
            "Administrators"
        ]
    }
}
----
