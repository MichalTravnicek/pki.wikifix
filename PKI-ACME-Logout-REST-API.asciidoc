= Overview

The Logout operation will read the session ID provided via cookie, then invalidate the session on the server.

= Request

* *URL:* `/acme/login`
* *Method:* `POST`
* *Auth required:* Yes

= Response

== Success Response
* *Code:* `200 OK`

== Error Response
* *Code:* `401 Unauthorized`
