= Request

* Path: `/ca/rest/admin/groups/{groupID}`
* Method: `DELETE`
* Authentication: Client certificate
* Parameters:
** `groupID`: string
* Content: None

= Example

----
curl -k -X "DELETE" --user caadmin:Secret.123 -s https://localhost.localdomain:8443/ca/rest/admin/groups/Enterprise%20TPS%20Administrators
----

* Second run, group no longer exists:

----
curl -k -X "DELETE" -H "Accept: application/json" --user caadmin:Secret.123 -s https://localhost.localdomain:8443/ca/rest/admin/groups/Enterprise%20TPS%20Administrators | python -m json.tool
{
    "Attributes": {
        "Attribute": []
    },
    "ClassName": "com.netscape.certsrv.base.ResourceNotFoundException",
    "Code": 404,
    "Message": "No such object."
}
----
