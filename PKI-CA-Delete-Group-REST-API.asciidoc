= Request

* Path: `/ca/rest/admin/groups/{groupID}`
* Method: `DELETE`
* Authentication: Client certificate
* Parameters:
** `groupID`: string
* Content: None

= Source
https://github.com/dogtagpki/pki/blob/e3cf3373074fc0ec7e4ecd110c9f4b1c4570e5de/base/server/src/main/java/org/dogtagpki/server/rest/GroupService.java#L298-L337[GroupService.removeGroup()]

= Example

----
curl \
  -k \
  -s \
  -X "DELETE" \
  --user caadmin:Secret.123 \
  https://localhost.localdomain:8443/ca/rest/admin/groups/Enterprise%20TPS%20Administrators
----
