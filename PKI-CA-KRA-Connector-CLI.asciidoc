= Creating KRA Connector =

Specify the KRA connector configuration in an XML file:

----
<?xml version="1.0" encoding="UTF-8" standalone="yes"?>
<kraConnectorInfo>
    <host>pki.example.com</host>
    <port>8443</port>
    <transportCert>... base-64 encoded transport certificate ...</transportCert>
    <uri>/kra/agent/kra/connector</uri>
    <timeout>30</timeout>
    <local>false</local>
    <enable>true</enable>
</kraConnectorInfo>
----

----
$ pki -n caadmin ca-kraconnector-add --input-file kra-connector.xml
-------------------
Added KRA connector
-------------------
----

= Adding KRA Host =

----
$ pki -n caadmin ca-kraconnector-add --host pki.example.com --port 8443
-------------------------------------
Added KRA host "pki.example.com:8443"
-------------------------------------
----

= Deleting KRA Host =

----
$ pki -n caadmin ca-kraconnector-del --host pki.example.com --port 8443
---------------------------------------
Removed KRA host "pki.example.com:8443"
---------------------------------------
----

= Deleting KRA Connector =

When the last KRA host is removed, the KRA connector will be removed automatically.
