= Request =

* **Path:** `/ca/rest/agent/certrequests`
* **Method:** `GET`
* **Authentication:** required
* **Query Parameters:**
** `requestState`: string
** `requestType`: string
** `start`: dec/hex request ID
** `pageSize`: integer
** `maxResults`: integer
** `maxTime`: integer
* **Content:** None

= Examples =

.JSON
[%collapsible]
====
----
$ curl \
    -k \
    -s \
    -H "Accept: application/json" \
    --user caadmin:Secret.123 \
    https://localhost.localdomain:8443/ca/rest/agent/certrequests | python -m json.tool
{
    "total": 6,
    "entries": [
        {
            "requestType": "enrollment",
