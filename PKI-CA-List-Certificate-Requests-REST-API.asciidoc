= Request

* Path: `/ca/rest/agent/certrequests`
* Method: `GET`
* Authentication: client certificate
* Query Parameters:
** `requestState`: string
** `requestType`: string
** `start`: dec/hex request ID
** `pageSize`: integer
** `maxResults`: integer
** `maxTime`: integer
* Content: None
