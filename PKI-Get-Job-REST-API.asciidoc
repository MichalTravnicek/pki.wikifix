= Request =

* **Path:** `/<subsystem>/rest/jobs/<ID>`
* **Method:** `GET`
* **Authentication:** User must be a member of `Administrators` group or a job owner
* **Content:** None
* **Success code:** `200`

= Examples =

----
$ curl \
  -k \
  -s \
  -H "Accept: application/json" \
  --user caadmin:Secret.123 \
  https://localhost.localdomain:8443/ca/rest/jobs/publishCerts | python -m json.tool
