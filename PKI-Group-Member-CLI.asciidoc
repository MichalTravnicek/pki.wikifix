= Overview =

All group member commands must be executed as an administrator.

= Listing Group Members =

----
$ pki <administrator authentication> group-find-member <group ID>
----

= Adding Group Member =

----
$ pki <administrator authentication> group-add-member <group ID> <member ID>
----

= Deleting Group Member =

----
$ pki <administrator authentication> group-remove-member <group ID> <member ID>
----
