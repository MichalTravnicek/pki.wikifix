= Overview =

The `pki <subsystem>-job` commands provide an interface to manage jobs in the subsystem.

**Availability:** Since PKI 11.3.

= Display Available Jobs =

To display available jobs in the subsystem:

----
$ pki -n caadmin ca-job-find
  Job ID: certRenewalNotifier
  Enabled: false
  Cron: 0 3 * * 1-5
  Plugin: RenewalNotificationJob

  Job ID: publishCerts
  Enabled: false
  Cron: 0 0 * * 2
  Plugin: PublishCertsJob

  Job ID: requestInQueueNotifier
  Enabled: false
  Cron: 0 0 * * 0
  Plugin: RequestInQueueJob

  Job ID: unpublishExpiredCerts
  Enabled: false
  Cron: 0 0 * * 6
  Plugin: UnpublishExpiredJob
----

= Display Job Details =

----
$ pki -n caadmin ca-job-show unpublishExpiredCerts
  Job ID: unpublishExpiredCerts
  Enabled: false
  Cron: 0 0 * * 6
  Plugin: UnpublishExpiredJob

  Parameters:
  - summary.emailSubject: Expired Certs Unpublished Summary
  - summary.emailTemplate: /var/lib/pki/pki-tomcat/ca/emails/euJob1.html
  - summary.enabled: true
  - summary.itemTemplate: /var/lib/pki/pki-tomcat/ca/emails/euJob1Item.html
  - summary.recipientEmail: 
  - summary.senderEmail: 
----

= Starting a Job Manually =

To start a job manually:

----
$ pki -n caadmin ca-job-start unpublishExpiredCerts
----
