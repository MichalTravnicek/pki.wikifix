= Displaying Transport Certificate =

----
$ pki kra-cert-transport-show
----

= Exporting Transport Certificate =

To export the transport certificate in PEM format:

----
$ pki kra-cert-transport-export
----

To export the transport certificate in DER format:

----
$ pki kra-cert-transport-export --type DER
----

To export the transport certificate into a file:

----
$ pki kra-cert-transport-export --file transport.crt
----
