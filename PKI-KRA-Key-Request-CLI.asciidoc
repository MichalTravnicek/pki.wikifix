= Overview =

All key request operations should be executed as KRA agent.

= Listing Key Requests =

To list submitted key requests:

----
$ pki -n caadmin kra-key-request-find
-----------------
1 entries matched
-----------------
  Request ID: 0x5319ddf580177086cc73d9386075128e
  Key ID: 0x008a590f503cbdf4d20de4de480473f19a
  Type: asymkeyGenRequest
  Status: complete
  Creation Time: Wed Oct 26 20:16:21 UTC 2022
  Modification Time: Wed Oct 26 20:16:21 UTC 2022
----------------------------
Number of entries returned 1
----------------------------
----

= Displaying Key Request =

To display a key request:

----
$ pki -n caadmin kra-key-request-show 0x5319ddf580177086cc73d9386075128e
  Request ID: 0x5319ddf580177086cc73d9386075128e
  Key ID: 0x008a590f503cbdf4d20de4de480473f19a
  Type: asymkeyGenRequest
  Status: complete
  Creation Time: Wed Oct 26 20:16:21 UTC 2022
  Modification Time: Wed Oct 26 20:16:21 UTC 2022
----
