= Request =

* **Path:** `/<subsystem>/rest/account/login`
* **Method:** `GET`
* **Authentication:** Not required
* **Content:** None
* **Success code:** `200`

= Source =

https://github.com/dogtagpki/pki/blob/e3cf3373074fc0ec7e4ecd110c9f4b1c4570e5de/base/server/src/main/java/org/dogtagpki/server/rest/AccountService.java#L84-L93[AccountService.login()]

    -k \
    -s \
    -H "Accept: application/json" \
    --user caadmin:Secret.123 \
    --cookie-jar cookies \
    https://localhost.localdomain:8443/ca/rest/account/login | python -m json.tool
