= Request

* Method: `GET`
* Path: `/<subsystem>/rest/account/logout`
* Authentication: Not required
* Content: None
* Success code: `204`

= Source
https://github.com/dogtagpki/pki/blob/e3cf3373074fc0ec7e4ecd110c9f4b1c4570e5de/base/server/src/main/java/org/dogtagpki/server/rest/AccountService.java#L95-L106[AccountService.logout()]
