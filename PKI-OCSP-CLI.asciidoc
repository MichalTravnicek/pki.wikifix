= Overview =

PKI provides CLI to access various OCSP services.

To list all available OCSP services: 

----
$ pki ocsp
Commands:
 ocsp-audit                Audit management commands
 ocsp-cert                 Certificate management commands
 ocsp-group                Group management commands
 ocsp-selftest             Selftest management commands
 ocsp-user                 User management commands
----
