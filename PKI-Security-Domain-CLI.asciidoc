= Overview =

The `pki securitydomain` commands can be used to manage a link:Security-Domain[Security Domain].

= Displaying Security Domain Info =

To display the security domain info:

----
$ pki securitydomain-show
  Domain: EXAMPLE

  CA Subsystem:

    Host ID: CA pki.example.com 8443
    Hostname: pki.example.com
    Port: 8080
    Secure Port: 8443
    Domain Manager: TRUE

  KRA Subsystem:

    Host ID: KRA pki.example.com 8443
    Hostname: pki.example.com
    Port: 8080
    Secure Port: 8443
    Domain Manager: FALSE

----

= Joining Security Domain =

----
$ pki \
    -d /etc/pki/pki-tomcat/alias \
    -f /etc/pki/pki-tomcat/password.conf \
    securitydomain-join \
    "KRA pki.example.com 8443" \
    --install-token <token> \
    --type KRA \
    --hostname pki.example.com
----

= Leaving Security Domain =

----
$ pki \
    -d /etc/pki/pki-tomcat/alias \
    -f /etc/pki/pki-tomcat/password.conf \
    -n subsystem \
    securitydomain-leave \
    "KRA pki.example.com 8443" \
    --type KRA \
    --hostname pki.example.com
----
