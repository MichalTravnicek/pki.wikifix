= Overview =

PKI provides CLI to manage security domain.

----
<?xml version="1.0" encoding="UTF-8" standalone="no"?>
<DomainInfo>
  <Name>EXAMPLE</Name>
  <CAList>
    <CA>
      <Host>localhost</Host>
      <UnSecurePort>8080</UnSecurePort>
      <SecurePort>8443</SecurePort>
      <SecureEEClientAuthPort>8443</SecureEEClientAuthPort>
      <SecureAgentPort>8443</SecureAgentPort>
      <SecureAdminPort>8443</SecureAdminPort>
      <Clone>FALSE</Clone>
      <SubsystemName>CA localhost.localdomain 8443</SubsystemName>
      <DomainManager>TRUE</DomainManager>
    </CA>
    <SubsystemCount>1</SubsystemCount>
  </CAList>
  <KRAList>
    <SubsystemCount>0</SubsystemCount>
  </KRAList>
  <OCSPList>
    <SubsystemCount>0</SubsystemCount>
  </OCSPList>
  <TKSList>
    <SubsystemCount>0</SubsystemCount>
  </TKSList>
  <RAList>
    <SubsystemCount>0</SubsystemCount>
  </RAList>
  <TPSList>
    <SubsystemCount>0</SubsystemCount>
  </TPSList>
</DomainInfo>
----

= Displaying Security Domain Info =

Security domain info can be viewed anonymously:

----
$ pki securitydomain-show
  Domain: EXAMPLE

  CA Subsystem:

    Host ID: CA ca.example.com 8443
    Hostname: ca.example.com
    Port: 8080
    Secure Port: 8443
    Domain Manager: TRUE

  KRA Subsystem:

    Host ID: KRA ca.example.com 8443
    Hostname: ca.example.com
    Port: 8080
    Secure Port: 8443
    Domain Manager: FALSE

----
