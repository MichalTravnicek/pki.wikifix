= Preparing CA Clone =

To export the CA system certificates for cloning, execute the following command:

----
$ pki-server ca-clone-prepare --pkcs12-file ca-certs.p12 --pkcs12-password-file password.txt
----

See also link:https://github.com/dogtagpki/pki/blob/master/docs/installation/ca/Installing_CA_Clone.md[Installing CA Clone].
