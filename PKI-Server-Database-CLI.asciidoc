= Overview =

PKI provides tools to upgrade the internal LDAP database.

= Displaying Database Status (Not Implemented Yet) =

----
$ pki-server db-status
  Hostname: server.example.com
  Port: 636
  SSL: yes
  Client Certificate: subsystemCert pki-tomcat
----

= Database Upgrade =

The pki-server db-upgrade is a tool to upgrade PKI server LDAP database. Currently the upgrade includes:

* link:https://github.com/dogtagpki/pki/issues/2226[Ticket #2226: adding issuerName attribute]

See link:https://github.com/dogtagpki/pki/blob/master/base/server/python/pki/server/cli/db.py[db.py] for details.

This tool is used as part of link:https://github.com/dogtagpki/pki/blob/master/docs/upgrade/v10.2/Upgrading_PKI_Database.adoc[Database Upgrade for PKI 10.2.x]. To run the database upgrade:

----
$ pki-server db-upgrade
----------------
Upgrade complete
----------------
----

= Schema Upgrade =

The pki-server db-schema-upgrade is a tool to upgrade PKI server LDAP schema. Currently the upgrade includes:

* re-applying link:https://github.com/dogtagpki/pki/blob/master/base/server/share/conf/schema.ldif[/usr/share/pki/server/conf/schema.ldif]

See link:https://github.com/dogtagpki/pki/blob/master/base/server/python/pki/server/cli/db.py[db.py] for details.

----
$ pki-server db-schema-upgrade -D "cn=Directory Manager" -w Secret.123
----------------
Upgrade complete
----------------
----
