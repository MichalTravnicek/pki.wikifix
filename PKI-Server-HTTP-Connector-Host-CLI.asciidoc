= Overview (UNDER CONSTRUCTION) =

PKI provides tools to manage SSL host configuration.

Available since: PKI 10.7.

= Listing SSL Hosts =

----
$ pki-server http-connector-host-find Secure
-----------------
1 entries matched
-----------------
  Hostname: _default_
  SSL Protocol: SSL
  Certificate Verification: optional
  Trust Manager: org.dogtagpki.tomcat.PKITrustManager
----

= Adding SSL Host =

----
$ pki-server http-connector-host-add Secure _default_ \
    --sslProtocol SSL \
    --certVerification optional \
    --trustManager org.dogtagpki.tomcat.PKITrustManager
----

= Deleting SSL Host =

----
$ pki-server http-connector-host-del Secure _default_
----
