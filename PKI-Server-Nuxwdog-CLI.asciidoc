= Overview =

The following commands can be used to manage nuxwdog configuration.

= Enabling Nuxwdog =

To enable nuxwdog on a single instance (default: pki-tomcat):

----
$ pki-server nuxwdog-enable [-i <instance ID>]
-------------------------------------------
Nuxwdog enabled on instance "<instance ID>"
-------------------------------------------
----

To enable nuxwdog on all instances:

----
$ pki-server nuxwdog-enable --all
-------------------------
Nuxwdog enabled on system
-------------------------
----

= Disabling Nuxwdog =

To disable nuxwdog on a single instance (default: pki-tomcat):

----
$ pki-server nuxwdog-disable [-i <instance ID>]
--------------------------------------------
Nuxwdog disabled on instance "<instance ID>"
--------------------------------------------
----

To disable nuxwdog on all instances:

----
$ pki-server nuxwdog-disable --all
--------------------------
Nuxwdog disabled on system
--------------------------
----
