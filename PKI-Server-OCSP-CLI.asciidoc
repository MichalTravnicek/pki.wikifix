= Preparing OCSP Clone =

To export the OCSP system certificates for cloning, execute the following command:

----
$ pki-server ocsp-clone-prepare --pkcs12-file ocsp-certs.p12 --pkcs12-password-file password.txt
----

See also link:https://github.com/dogtagpki/pki/blob/master/docs/installation/ocsp/Installing_OCSP_Clone.md[Installing OCSP Clone]
