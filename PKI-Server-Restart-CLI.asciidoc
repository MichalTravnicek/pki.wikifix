= Overview =

The `pki-server restart` command can be used to restart a PKI Tomcat server or a standard Tomcat server that is running in the background. 

= Restarting PKI Tomcat Server =

To restart a PKI Tomcat server execute the following command:

----
$ pki-server restart pki-tomcatd@<name>
----

or simply:

----
$ pki-server restart <name>
----

= Restarting Standard Tomcat Server =

To restart a standard Tomcat server execute the following command:

----
$ pki-server restart tomcat@<name>
----
