= Overview =

The `pki-server stop` command can be used to stop a PKI Tomcat server or a standard Tomcat server that is running in the background. 

= Stopping PKI Tomcat Server =

To stop a PKI Tomcat server execute the following command:

----
$ pki-server stop pki-tomcatd@<name>
----

or simply:

----
$ pki-server stop <name>
----

= Stopping Standard Tomcat Server =

To stop a standard Tomcat server execute the following command:

----
$ pki-server stop tomcat@<name>
----
