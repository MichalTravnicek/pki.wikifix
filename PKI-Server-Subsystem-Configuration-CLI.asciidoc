= Displaying Subsystem Configuration =

To display all subsystem configuration parameters:

----
$ pki-server <subsystem>-config-find
----

To display a specific subsystem configuration parameter:

----
$ pki-server <subsystem>-config-show <parameter>
----

= Modifying Subsystem Configuration =

To set or change a configuration parameter:

----
$ pki-server <subsystem>-config-set <parameter> <value>
----

= Removing Subsystem Configuration =

To remove a configuration parameter:

----
$ pki-server <subsystem>-config-unset <parameter>
----
