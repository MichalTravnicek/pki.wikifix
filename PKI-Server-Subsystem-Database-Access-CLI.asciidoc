= Overview (Not Yet Implemented) =

The `pki-server <subsystem>-db-access` commands provide an interface for managing database access.

= Granting Access to a User =

----
$ pki-server ca-db-access-grant uid=pkidbuser,ou=people,dc=ca,dc=example,dc=com
----

= Revoking Access from a User =

----
$ pki-server ca-db-access-revoke uid=pkidbuser,ou=people,dc=ca,dc=example,dc=com
----
