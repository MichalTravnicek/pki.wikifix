= Overview =

The `pki-server <subsystem>-db-access` commands can be used to manage access to PKI database.

= Granting Database Access =

To grant database access to a user:
----
$ pki-server ca-db-access-grant uid=pkidbuser,ou=people,dc=ca,dc=pki,dc=example,dc=com
----

This command will execute the LDAP operations specified in link:https://github.com/edewata/pki/blob/install/base/server/share/conf/db-access-grant.ldif[/usr/share/pki/server/conf/db-access-grant.ldif].

= Revoking Database Access =

To revoke database access from a user:
----
$ pki-server ca-db-access-revoke uid=pkidbuser,ou=people,dc=ca,dc=pki,dc=example,dc=com
----

This command will execute the LDAP operations specified in link:https://github.com/edewata/pki/blob/install/base/server/share/conf/db-access-revoke.ldif[/usr/share/pki/server/conf/db-access-revoke.ldif].
