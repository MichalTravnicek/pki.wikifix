= Overview (Not Implemented) =

The `pki-server <subsystem>-db-repl` commands can be used to manage subsystem database replication.

= Setting Up Replication =

----
$ pki-server <subsystem>-db-repl-setup \
    --master-replication-port <port> \
    --replica-replication-port <port> \
    --replication-security <security>
----

= Adding Replication Manager =

----
$ pki-server <subsystem>-db-repl-manager-add <name> --password <password>
----

= Removing Replication Manager =

----
$ pki-server <subsystem>-db-repl-manager-del <name>
----

= Adding Replication Object =

----
$ pki-server <subsystem>-db-repl-add
----

= Removing Replication Object =

----
$ pki-server <subsystem>-db-repl-del
----

= Adding Replication Agreement =

----
$ pki-server <subsystem>-db-repl-agreement-add <name> \
    --hostname <hostname> \
    --port <port> \
    --security <security> \
    --user <user> \
    --password <password>
----

= Removing Replication Agreement =

----
$ pki-server <subsystem>-db-repl-agreement-del <name>
----

= Starting Replication =

----
$ pki-server <subsystem>-db-repl-start
----

= Stopping Replication =

----
$ pki-server <subsystem>-db-repl-stop
----
