= Overview =

The `pki-server <subsystem>-db-replication-setup` can be used to set up the replication for the subsystem database.

= Setting Up Replication (Not Implemented) =

----
$ pki-server <subsystem>-db-replication-setup \
    --master-replication-port <port> \
    --replica-replication-port <port> \
    --replication-security <security>
----

= Removing Replication (Not Implemented) =

----
$ pki-server <subsystem>-db-replication-remove
----
