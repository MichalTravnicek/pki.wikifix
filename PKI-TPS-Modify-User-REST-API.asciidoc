= TPS Operation

* op=save_user
* op=add_profile_user

= REST Operation

* PUT /tps/rest/users/<User ID>

= Request

* User ID
* First name
* Last name
* Roles (operator, agent, admin)
* Base-64 encoded user certificate
* Profiles
* ETag
* Nonce

= Response

* HTTP 200 OK
* User ID
* First name
* Last name
* Roles (operator, agent, admin)
* Base-64 encoded user certificate
* Profiles
* ETag
