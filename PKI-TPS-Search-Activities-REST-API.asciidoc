= TPS Operation

* op=view_activity
* op=view_activity_all
* op=view_activity_admin_all

= REST Operation

* GET /tps/rest/users

= Request

* Token ID
* User ID
* Page number (default: 1)
* Page size (default: 20)

= Response

* HTTP 200 OK
* Activities in the requested page:
** Activity ID
** Token ID
** IP
** User ID
** Operation
** Result
** Date created
