= TPS Operation

* op=select_config_parameter&ptype=Profiles
* op=agent_select_config&ptype=Profiles

= REST Operation

* GET /tps/rest/profiles

= Request

* Page number (default: 1)
* Page size (default: 20)

= Response

* HTTP 200 OK
* Result size
* Profiles in the requested page:
** Profile ID

= Access Control

* operators: denied
* agents: allowed
* admins: allowed
* default: denied
