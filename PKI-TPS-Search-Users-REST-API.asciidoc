= TPS Operation

* op=view_users

= REST Operation

* GET /tps/rest/users

= Request

* User ID
* First name
* Last name
* Page number (default: 1)
* Page size (default: 20)

= Response

* HTTP 200 OK
* Result size
* Users in the requested page:
** User ID
** First name
** Last name
** Date created
** Date modified
