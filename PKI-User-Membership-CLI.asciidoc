= Overview =

PKI provides CLI to manage user memberships. All user membership commands must be executed as an administrator.

= Commands =

== Listing user memberships ==

----
$ pki -n caadmin ca-user-membership-find <user ID>
----

== Adding user membership ==

----
$ pki -n caadmin ca-user-membership-add <user ID> <group ID>
----

== Deleting user membership ==

----
$ pki -n caadmin ca-user-membership-del <user ID> <group ID>
----
