= Prerequisites =

```
$ dnf install maven
```

= Getting RESTEasy Source =

```
$ git clone https://github.com/resteasy/Resteasy.git
$ cd Resteasy
$ git checkout -b 3.0.26 3.0.26.Final
```

= Creating Eclipse Project =

```
$ mvn eclipse:eclipse
```

= Building RESTEasy =

```
$ mvn compile
```
