= Installation =

To install Eclipse on Fedora:

----
$ dnf install eclipse-jdt
----

It should add an icon in the desktop's *Favorites*.

= Adding a Project =

First, clone the project into a local repository, for example:

----
$ git clone git@github.com:dogtagpki/pki.git
----

To add the project into Eclipse:

* Click *File* -> *New* -> *Java Project*.
* Enter the *Project name*, e.g. `pki`.
* Uncheck *Use default location*.
* Enter the path to the cloned project repository, e.g. `/home/<username>/Projects/pki`.
* Click *Finish*.
