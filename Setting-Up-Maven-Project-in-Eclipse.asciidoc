= Installation =

Install link:http://download.eclipse.org/technology/m2e/releases[M2Eclipse] plugin.

= Creating Maven Project =

To generate Eclipse project files:

----
$ mvn eclipse:clean
$ mvn eclipse:eclipse
----

= Converting Java Project into Maven Project =

To convert a Java project into a Maven project:

* Right click on project
* Select Configure
* Select Convert to Maven Project

To update Maven dependencies:

* Right click on project
* Select Maven
* Select Update Project
* Select Force Update of Snapshots/Releases
* Select OK
