= Installation =

* Go to **Help** > **Install New Software**.
* Enter http://pydev.org/updates.
* Select **PyDev**.
* Click **Next**.
* Accept license agreements.
* Click **Finish**.

= Configuration =

* Go to **Window** > **Preferences** > **PyDev** > **Interpreters** > **Python Interpreters**.
* Click **Quick Auto-Config**.
* Click **OK**.
