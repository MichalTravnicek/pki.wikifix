= Overview =

This page describes the process to set up a TKS database using DS.
It assumes that the DS database has been installed as described in link:DS-Installation[DS Installation].

*Availability:* Since PKI 11.5

= Initializing TKS Database =

----
$ pki-server tks-db-init
----

= Adding TKS Search Indexes =

----
$ pki-server tks-db-index-add
----

= Rebuilding TKS Search Indexes =

----
$ pki-server tks-db-index-rebuild
----

= Adding TKS VLV Indexes =

----
$ pki-server tks-db-vlv-add
----

= Rebuilding TKS VLV Indexes =

----
$ pki-server tks-db-vlv-reindex
----
