= Overview =

This page describes the process to submit a certificate renewal request.

For older versions see:

* link:PKI-10.3-Submitting-Certificate-Renewal-Request[PKI 10.3 Submitting Certificate Renewal Request]

= Submitting Certificate Renewal Request =

To submit a renewal request for a certificate:

----
$ pki ca-cert-request-submit --profile caManualRenewal --serial 0x6 --renewal
-----------------------------
Submitted certificate request
-----------------------------
  Request ID: 28
  Type: renewal
  Request Status: pending
  Operation Result: success
----

To submit a renewal request for a CA certificate:

----
$ pki ca-cert-request-submit --profile caCACert --csr-file ca_signing.csr --renewal --serial 0x1
-----------------------------
Submitted certificate request
-----------------------------
  Request ID: 7
  Type: enrollment
  Request Status: pending
  Operation Result: success
----
