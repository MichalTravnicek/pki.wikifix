= Overview =

The `TOKEN_CERT_RETRIEVAL` audit event is generated when token certificate retrieval request is made.

Properties:

* `CUID`: card unique ID
* `MSN`: manufacturer serial number
* `TokenType`: TPS profile name
* `Serial`: serial number in decimal
* `CA_ID`: CA id as defined in TPS CS.cfg
* `KRA_ID`: KRA id as defined in TPS CS.cfg
