= Overview =

The `TOKEN_KEY_RECOVERY` audit event is generated when token certificate key recovery request is made.

= Examples =

----
[AuditEvent=TOKEN_KEY_RECOVERY][IP={0}][SubjectID={1}][CUID={2}][Outcome={3}][to
kenType={4}][KeyVersion={5}][Serial={6}][CA_ID={7}][KRA_ID={8}][Info={9}] token 
certificate/key recovery request made
----
