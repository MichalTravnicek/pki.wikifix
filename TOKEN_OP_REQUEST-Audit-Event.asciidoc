= Overview =

The `TOKEN_OP_REQUEST` audit event is triggered when token processor op request made.

* `OP` can be `format`, `enroll`, or `pinReset`

= Examples =

----
[AuditEvent=TOKEN_OP_REQUEST][IP={0}][CUID={1}][MSN={2}][Outcome={3}][OP={4}][Ap
pletVersion={5}] token processor op request made
----
