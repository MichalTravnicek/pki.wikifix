= Managing Tokens =

== Listing Tokens ==

* Open TPS UI.
* Click Tokens.

== Viewing Token Details ==

* Open TPS UI.
* Click Tokens.
* Click the token of interest.

== Searching Tokens ==

* Open TPS UI.
* Click Tokens.
* Enter search keyword in Search box.
* Click Enter.

The table will be updated to show the tokens matching the search keyword.

== Editing the Token Information ==

* Open TPS UI.
* Click Tokens.
* Click the token to be updated.
* Click Edit.
* Change the token information.
* Click Save.

== Changing the Token Policy ==

* Open TPS UI.
* Click Tokens.
* Click the token to be updated.
* Click Edit.
* Change the token policy.
* Click Save.

== Changing Token Status ==

* Open TPS UI.
* Click Tokens.
* Click the current status of the token to be updated.
* Select the new status.
* Click Save.

Alternatively:

* Open TPS UI.
* Click Tokens.
* Click the token to be updated.
* Click Change Status.
* Select the new status.
* Click Save.

= Managing Token Certificates =

To browse all certificates:

* Open TPS UI.
* Click Certificates.

To view certificate details:

* Open TPS UI.
* Click Certificates.
* Click the certificate of interest.

To search for certain certificates:

* Open TPS UI.
* Click Certificates.
* Enter search keyword in the Search box.
* Click Enter.

The table will be updated to show certificates matching the search keyword.

To list certificates belonging to a token:

* Open TPS UI.
* Click Tokens.
* Click the token of interest.
* Click Show Certificates.

= Managing Token Profiles =

== Listing Profiles ==

* Open TPS UI.
* Click System.
* Click Profiles.

== Viewing Profile Details ==

* Open TPS UI.
* Click System.
* Click Profiles.
* Click the profile of interest.

== Enabling a Profile ==

* Open TPS UI.
* Click System.
* Click Profiles.
* Click the profile to update.
* Click Disable.
* Click OK.

== Disabling a Profile ==

* Open TPS UI.
* Click System.
* Click Profiles.
* Click the profile to update.
* Click Enable.
* Click OK.
