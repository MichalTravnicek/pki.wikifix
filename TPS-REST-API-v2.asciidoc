= Overview =

This page describes the services provided by TPS REST API v2.

WARNING: This feature is still under development. The API might still change. Do not use it in production.

= Activity Services =

|===
| Path | Method | Service

| `/tps/v2/activities`
| `GET`
| List Activities

| `/tps/v2/activities/{id}`
| `GET`
| Get Activity

|===
