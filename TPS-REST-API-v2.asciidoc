= Overview =

This page describes the services provided by TPS REST API v2.

WARNING: This feature is still under development. The API might still change. Do not use it in production.

= Token Services

|===
| Path | Method | Service

| `/tps/v2/tokens`
| `GET`
| Search Tokens

| `/tps/v2/tokens`
| `POST`
| Add Token

| `/tps/v2/tokens/{id}`
| `GET`
| Get Token

| `/tps/v2/tokens/{id}`
| `PATCH`
| Modify Token

| `/tps/v2/tokens/{id}`
| `POST`
| Change Token State

| `/tps/v2/tokens/{id}`
| `DELETE`
| Remove Token

|===

= Activity Services =

|===
| Path | Method | Service

| `/tps/v2/activities`
| `GET`
| List Activities

| `/tps/v2/activities/{id}`
| `GET`
| Get Activity

|===
