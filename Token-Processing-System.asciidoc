= Overview =

The Token Processing System (TPS) provides the registration authority functionality in the token management infrastructure and establishes secure channels between the Enterprise Security Client and the back-end subsystems (CA, KRA, and TKS).

The TPS subsystem serves as the conduit between the link:Enterprise-Security-Client[Enterprise Security Client] a.k.a. (Smart Card Manager) and the other subsystems (CA, KRA, TKS) in the Dogtag Certificate System and is the only means for the client to communicate with the other subsystems.
