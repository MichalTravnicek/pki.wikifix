= Upgrading PKI 10 Server =

In general PKI 10 server can be upgraded with the following procedure:

* Shutdown PKI server
* Upgrade the PKI packages
* Follow the link:Upgrading-PKI-Database[database upgrade] procedure to upgrade PKI database
* Restart PKI server

Certain versions may require specific upgrade procedure:

* link:Upgrading-PKI-10.5-to-PKI-10.6[Upgrading PKI 10.5 to PKI 10.6]

= Upgrading PKI 9 Server =

PKI 9 server cannot be upgraded directly to PKI 10, but it can be migrated into a new PKI 10 server.

* link:Migrating-PKI-Server[Migrating PKI Server]
