= Rules =

Rules are stored in `/etc/fapolicyd/rules.d` folder. The rules for each PKI server are defined in `61-pki-<instance>.rules` file:

----
allow perm=open dir=/usr/lib/jvm/ : dir=/var/lib/pki/<instance>/work/Catalina/localhost/
----
